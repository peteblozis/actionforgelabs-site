# BuySignal Product Charter

## Product Name
BuySignal

## One-Line Promise
BuySignal watches buying conditions and alerts users only when it is time to act.

## Customer Problem
People and small businesses waste time checking prices manually and often miss the right purchase moment.

## Target Users
- Consumers tracking high-value purchases
- Small-business owners
- Purchasing managers
- Resellers
- Families managing recurring product purchases
- Early testers through ActionForge Labs

## Core Workflow
1. User enters product name.
2. User enters exact product/variant requirement.
3. User sets target price.
4. User enters or later receives current price.
5. BuySignal shows BUY NOW or WAIT.
6. Production version sends alerts only when action is needed.

## Product Boundary
BuySignal is the customer-facing product. PriceWatch is only the legacy/internal module name.

## Production Gap
Live price collection requires a backend connector or approved data source.
